# Community Code of Conduct

The Edge Download Manager (EDM) open source project is committed to providing a friendly, safe, and welcoming environment for all contributors and users, regardless of background, identity, or experience level.

## Project Guidelines

1. **Respect and Professionalism**: Treat all community members with courtesy, empathy, and constructive feedback. Harassment, derogatory comments, or personal attacks will not be tolerated.
2. **Constructive Collaboration**: Focus on what is best for the project, community, and users. Welcome new contributors and help others learn.
3. **Open and Transparent Communication**: Project decisions, architecture proposals, and issue triage are conducted transparently in public GitHub discussions, issues, and pull requests.
4. **Safety and Integrity**: Maintain high standards for software safety, user privacy, and defensive security.

## Enforcement & Reporting

Project maintainers are responsible for clarifying standards of acceptable behavior and will take appropriate, fair corrective action in response to any behavior deemed inappropriate or harmful.

To report violations or concerns privately, please reach out to the project maintainers at `edm@suvesh.dev`. All reports will be handled promptly and confidentially.
